📊 ModeloMLB - Predicción de MLB y KBO
Sistema de Machine Learning para la predicción de resultados y estadísticas de las ligas de béisbol MLB (Major League Baseball) y KBO (Korean Baseball Organization).

🎯 Descripción
ModeloMLB es un proyecto de ciencia de datos que utiliza modelos de Machine Learning para predecir:

Resultados de partidos

Estadísticas de jugadores

Props de lanzadores (K, BB, HR, etc.)

Tendencias de rendimiento

🛠️ Tecnologías Utilizadas
Python 3.12

Scikit-learn - Modelos de Machine Learning

Pandas - Manipulación de datos

NumPy - Cálculos numéricos

Matplotlib/Seaborn - Visualización de datos

BeautifulSoup/Requests - Web scraping

Joblib - Serialización de modelos
